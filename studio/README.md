# 冬藏季素材工作台

固定设计素材批量合成工具。图片和视频在客户的浏览器本地处理，服务端只提供静态网站文件。没有上传接口、账号、数据库、第三方统计或外部字体请求。

## 本地试用

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。点击“试用示例图片”可批量加载三张程序绘制的测试素材；示例不属于正式设计物料。

## 功能

- 内置 57 款原稿素材：37 款分层模板、4 款透明框、7 款 Logo/贴纸和 1 款竖转横视频模板可参与合成；8 款完整主题图/KV 可下载原图。支持分类筛选与搜索。
- 分层模板从提供的 PSD 中移除示例商品/人物层，保留背景、前景和原文案；没有改写源文件。原有两款透明框保持原 PNG 字节。
- 可导入透明 PNG 模板，最长边 3840px；视频模板宽高必须为偶数。
- 批量选择或拖放图片、视频，可以混合队列，顺序处理。
- 每个素材可单独设置铺满/完整显示、缩放、位置、底色。模板为整批共用，不能编辑模板内部设计。
- PNG / JPG 图片导出；H.264 MP4 视频导出，最高 30fps，保留原时长，可保留/去掉音轨。音轨不能兼容或转码时明确失败，避免悄悄丢失音频。
- 视频在 Web Worker 内通过 WebCodecs 和 Mediabunny 解码、合成、编码、封装。无需服务器渲染。
- 可选择本地输出文件夹，流式写盘；同名文件自动增加后缀，不覆盖已有文件。
- 没有文件夹权限时优先使用浏览器私有磁盘暂存（OPFS），逐个点击下载。无 OPFS 时退回有限内存暂存，视频输出上限 180MB，队列内存保护约 200MB。
- 单个失败不中断后续任务；支持停止和重试。停止时删除本次新建的未完成输出，已完成的文件保留。

## 试用边界

推荐电脑端新版 Chrome / Edge，并使用 HTTPS 或 localhost。手机及微信内置浏览器未作为第一版支持目标。选择文件不发送素材内容给服务器。

优先试用 1080p、3 分钟以内的视频。这是建议，不是已通过压力测试的上限。编码格式、硬件、磁盘剩余空间会影响速度与成功率。导出过程中保持页面打开。页面尝试使用屏幕唤醒锁，浏览器不支持时会正常继续。

模板是最终输出画布尺寸；选择横版框不会拉伸人物，默认等比例铺满并裁切，可切换“完整显示”保留完整画面。上传商品照片不会自动移除其背景。未自动抠除任何固定设计的白色区域。

队列不会跨刷新保存。清空队列会删除该队列的浏览器临时输出，不会删除已选文件夹里的成品。超过 24 小时的旧临时输出会在后续需要临时目录时清理；用户也可以通过清除站点数据删除。客户素材原文件不会被改写。

40 款含独立文字层的模板已支持 116 个可编辑字段（商品文案、活动信息、达人姓名、优惠券金额/条件等）；固定 Logo、无文字层的成图保持原样。文字从 PSD 提取字体、字号、基线位置、对齐、字距、渐变和阴影配置。未改动字段使用原始文字像素；修改后用原字体在本机渲染，浏览器与 Photoshop 的抗锯齿/阴影算法可能有细微差异。

文案可逐素材编辑、一键应用到全部，或下载当前队列 CSV，在 Excel 中填完再导入（UTF-8 CSV）。按完整文件名精确匹配；重名、未知文件名、未知列和格式错误会阻止整份导入。空值明确隐藏对应字段。模板切换保留各素材的文案。文字不自动缩放；超出原行数/字宽或包含原字体不支持的字符时，相关素材导出失败，其他任务继续。商品/人物模板建议使用透明 PNG 主体；完整照片不会自动抠图。竖版视频框原尺寸为奇数，视频输出在右/下补 1 像素以适配 H.264，图稿不拉伸。

素材库由 `scripts/build-catalog.py` 从本地原稿生成，静态站点无需包含 PSD/PSB。图片按选中模板加载，服务端只负责静态文件分发。

## 部署到小服务器

```sh
npm run build
```

将 `dist/` 的全部内容放到静态网站目录，通过 HTTPS 访问即可。运行时不需要 Node、FFmpeg、GPU 或数据库。相对资源路径支持部署到子目录。可用 Nginx、Caddy 或其他静态托管，正确返回 JS MIME 类型即可。不要对外开放 Vite 开发服务器。

服务器只消耗页面、代码、模板下载流量。WebCodecs 编解码和媒体合成完全在客户设备上进行。若后续新增统计、账号或云存储，应继续明确区分素材本地处理与联网功能。

## 验证

```sh
npm test
npm run build
```

几何测试覆盖等比例适配、留白、位移和缩放，文件命名测试覆盖路径字符和同名素材编号。浏览器端另实测批量图片生成、横/竖视频合成及音轨保留，不能以构建成功代替媒体导出验证。

第三方库：Mediabunny 1.61.3（MPL-2.0，许可证见 `public/licenses/mediabunny-MPL-2.0.txt`，源码见 https://github.com/Vanilagy/mediabunny/tree/v1.61.3 ）、Vite（MIT）。依赖版本固定在 `package-lock.json`。

字体来自 Adobe 官方 Source Han 仓库和荣耀官方字体包。思源字体使用 WOFF2 无损格式；HONOR Sans 保留原 TTF 文件，不修改字体，许可见 public/fonts。字体按当前模板加载，运行时不连接第三方字体服务。

重新生成素材目录：先运行 `.asset-venv/bin/python scripts/build-catalog.py`，再运行 `.asset-venv/bin/python scripts/extend-text-catalog.py`。原始 PSD/PSB 只读。


## 按比例自动套图与批量 Review

- 导入图片和视频时在本地读取实际尺寸（浏览器显示方向），按横／竖／方形、画幅及素材摆放区域匹配固定模板。默认完整显示，不改变原图稿尺寸与字体。
- 默认全库排除下载类原稿；贴片、Logo、竖转横包装需明确选为偏好或限定对应分类。可以限定自动匹配范围。比例匹配不识别行业或人物／商品语义，客户需检查选中的款式。
- 每个素材保存独立模板。点击模板只修改当前素材；“当前模板应用到全部”显式统一模板。“重新匹配”保留手动指定项目，“当前素材恢复自动匹配”解除该项目的手动指定。
- 导入后自动生成合成缩略图。视频检查 10%、50%、90% 三帧，可点击抽帧跳转预览、拖动进度或播放全片。
- Review 检查摆放区域的几何裁切／留白、素材放大与文案错误。不能判断主体是否被装饰遮挡；透明图片的像素边界与实际主体可能不同。人工确认是检查记录，不作为导出门槛。
- 修改模板、文案或适配后清除旧 Review 与人工确认，点击“更新 Review”重新检查。错误项可重试，成功项逐个按自己的模板导出。
- 混合模板时，批量文案与 CSV 只作用于当前模板对应的素材，防止不同模板字段误填。
- Sites：沿用 `.openai/hosting.json` 的项目 ID，访问范围为拿到链接即可访问。
